# Student profiles and printable reports

Added:
- Optional student photo selected from device.
- Optional student name and ID.
- Caregiver/SLP notes.
- Student profile stored in app-private storage.
- Printable PDF report generation.
- Report includes recording count, most frequent possible missing initial sounds, repeated words, and notes.
- Reports are stored locally in the app's private storage.

Privacy:
- Student identifying information and photos should be treated as sensitive.
- Keep cloud synchronization off by default.
- Provide deletion/export controls before production deployment.
- The report explicitly describes findings as app-generated observations rather than a clinical diagnosis.
