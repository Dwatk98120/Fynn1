# Clean Parent PC Build

This package contains one supported Parent PC application under `parent_pc_local/`.

Included features:
- Direct microphone recording
- Recording history
- Caregiver approval, correction, and rejection
- Batch WAV analysis
- AI Dashboard
- Evidence view
- Raw JSON inspection
- Candidate / changed-sound / dropped-sound analytics
- Manual API configuration and connection testing
- One-Tap phone pairing
- Bluetooth / local Wi-Fi-LAN support
- Recording-quality scoring
- Expanded phoneme analysis

There is no secondary Parent PC application in this package.
