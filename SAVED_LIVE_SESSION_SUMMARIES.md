# Saved Live Session Summaries

At the end of Live Speech, tap **Save Session Summary** to store the session locally.

Saved summaries are kept in the app-private `filesDir/live_session_summaries/` directory and contain:
- session duration
- observation count
- latest recognized speech
- possible missing initial sounds and counts
- candidate words and counts
- a non-diagnostic disclaimer

The summary is not automatically uploaded to the analysis server.
