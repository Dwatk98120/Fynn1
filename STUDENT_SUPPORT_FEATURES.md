# Student Support Features

- Favorite Phrases
- Picture + Voice Choices
- Try Again Practice
- Choice Board
- Quick Communication Needs
- Visual Progress (activity counts only)
- Teacher / Caregiver Notes
- Custom Vocabulary
- Privacy & Offline Mode
- Local Student Data Deletion
- Communication Modes
- Visual Sentence Builder
- Personal Word Bank integration

All of these are local-first UI supports. The app does not require a child to obtain a "correct" speech analysis result in order to communicate.
