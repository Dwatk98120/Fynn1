# Security

Please do not report private student information in GitHub issues.

Do not commit:
- child/student audio
- student names or IDs
- photos
- private notes
- API keys or passwords
- Android signing keys

If a secret is accidentally committed, revoke/rotate it immediately. Removing it in a later commit does not make the exposed value safe.

For privacy-sensitive reports, use a private communication channel rather than a public GitHub issue.
