# Phrase matching

Added a local phrase library.

Features:
- Save frequently used phrases.
- Exact normalized phrase matching.
- Similar phrase matching using word overlap and edit distance.
- Show a possible matching phrase after analysis.
- Display a match percentage as a non-clinical similarity measure.
- Confirm the matched phrase.
- Play saved phrases with Android text-to-speech.
- Delete individual phrases or the whole library.

This is an assistive matching feature, not a diagnostic or clinical score.
