# Built-in AAC Communication Focus

AAC remains part of the Android app, available offline. Caregivers can select Speech Understanding Focus, Speech + AAC Together (default), or AAC Communication Focus from Caregiver Setup or Student Communication Tools. The preference persists on-device. No features are downloaded or disabled. The Student Communication Tools button label and guidance reflect the choice. This is an initial organization pass; the main screen is not fully reordered.
