HEARLIUM PARENT PC — FULL WINDOWS SOURCE AND INSTALLER BUILDER

Extract the ZIP to a Windows folder.
Run CHECK_BUILD_ENVIRONMENT.bat to check prerequisites.
Read SDK_BLUETOOTH_BUILD_GUIDE.txt and WINDOWS_INSTALLER_README.txt.
Use BUILD_HEARLIUM_INSTALLER.bat for the installer build.
Python, required packages, .NET SDK for Bluetooth, and Inno Setup may be needed.

This is the source/build package, NOT an already built .exe installer.
Windows compilation and installation have not been verified in this environment.
