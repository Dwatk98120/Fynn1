FIRST SOUND HELPER — FULL ANDROID SOURCE PACKAGE

Recording indicator included directly in activity_main.xml and MainActivity.kt.
No separate CI patch script required.

To build with GitHub:
1. Extract this ZIP.
2. Upload the contents to the root of the intended Fynn1 branch (not into a new enclosing folder).
3. Open GitHub Actions > Build Android APK and run on that branch.
4. Download the newly generated first-sound-helper-debug-apk artifact.

This is source code, not a prebuilt APK. Build and phone tests were not performed here.
